# Spareprod Laravel

Aplikasi aktif yang sekarang dipakai untuk pengembangan ada di folder ini.

Folder yang paling sering digunakan:

- `resources/views` untuk tampilan Blade
- `public/theme` untuk CSS, JS, dan asset publik
- `app/Http/Controllers` untuk logic fitur
- `app/Models` untuk model data
- `routes` untuk route
- `database` untuk migration dan seeder
- `tests` untuk test Laravel

Menjalankan aplikasi:

```powershell
cd C:\Users\User\33\Spareprod\laravel
C:\laragon\bin\php\php-8.5.4-Win32-vs17-x64\php.exe artisan serve
```

Menjalankan test:

```powershell
cd C:\Users\User\33\Spareprod\laravel
C:\laragon\bin\php\php-8.5.4-Win32-vs17-x64\php.exe artisan test
```

Catatan:

- arsip Django/Python lama sudah dipindahkan ke `../cache/`
- pengembangan harian dilakukan di folder `laravel/`
